📚 School Attendance System


🚀 Overview

This is a simple School Attendance System built using HTML, CSS, and JavaScript.
The project was developed as a basic web application to track and manage student attendance in a straightforward and easy-to-use interface.


It is a lightweight system designed for learning purposes and small-scale use, and it runs entirely in the browser without any backend.


🛠️ Tech Stack
HTML,
CSS,
JavaScript


✨ Features
📝 Add student names
✅ Mark students as present or absent
📊 Simple visual display of attendance
💾 Data stored temporarily in the browser (no database)
⚡ Fast and easy to use


▶️ How to Use
Clone the repository
git clone <YOUR_GIT_URL>
Open the project folder
Run the project
Open the index.html file in your browser
Start using the system
Add students
Mark attendance
View results instantly


📌 Notes
This is a basic project built from scratch without using AI tools
It was tested locally in a browser environment
No backend or database is used
Data resets when the page is refreshed


🎯 Purpose

This project was created to practice:

JavaScript logic and DOM manipulation
Building simple user interfaces
Understanding how frontend-only applications work
